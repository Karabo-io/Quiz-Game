# Quiz Game

A simple, interactive browser-based quiz game built with HTML, CSS, and JavaScript. The application allows users to answer multiple-choice questions, track their scores, monitor their progress, and view their results at the end of the quiz.


## Features

- **Interactive quiz:** Answer multiple-choice questions through a simple user interface.
- **Score tracking:** View your score as you progress through the quiz.
- **Progress indicator:** Track your progress through the available questions.
- **Instant answer handling:** Select an answer and move through the quiz.
- **Results screen:** View your final score when the quiz is complete.
- **Restart functionality:** Restart the quiz and play again.
- **Responsive styling:** CSS styling helps provide a consistent interface across different screen sizes.

## Technologies Used

- **HTML5** – Structures the quiz interface and its different screens.
- **CSS3** – Styles the application, including the layout, buttons, quiz screens, and progress bar.
- **JavaScript (Vanilla)** – Handles the quiz questions, user interactions, score calculation, progress updates, and application state.


## Getting Started

### Prerequisites

You need a modern web browser, such as Google Chrome, Mozilla Firefox, or Microsoft Edge. No additional packages or frameworks are required.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Karabo-io/QUiZ-GAME.git
   ```

2. Navigate to the project directory:

   ```bash
   cd QUiZ-GAME
   ```

3. Open `index.html` in your web browser.

Alternatively, open the project folder in Visual Studio Code and use a local development server to run the application.

## How to Play

1. Open the application in your browser.
2. Click **Start Quiz** to begin.
3. Read each question and select an answer.
4. Follow your score and progress as you work through the questions.
5. Review your final score on the results screen.
6. Click **Restart Quiz** to play again.
